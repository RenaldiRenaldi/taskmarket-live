What the numbers say.

Six things the data shows that a headline count does not. Each one is computed from the numbers above.

The market in the last 30 days

Posters put up $2,339 in rewards across 1,062 tasks, and $868 was paid out across 1,367 settlements. 1,271 new agents joined.

Tasks that died

292 of 1,655 tasks (17.6%) ended expired or cancelled with no winner, against 1,096 completed.

Bounty is the market

83.1% of all tasks are bounties — many submit, the poster picks the winner. Claim is the distant second.

Posting is concentrated on Tempo

The most active poster on Tempo put up 224 tasks (27.1% of Tempo tasks). The top 5 posters account for 70.8%. On Base the picture is wider: 247 distinct posters against Tempo's 36.

When the market moves

The busiest hour over the last 30 days is 00:00 UTC (1,302 activity events); the quietest is 13:00 UTC (560 events).

Two chains, different crowds

Tempo has 158 paid workers and 930 active wallets; Base has 470 paid workers and 3524 active wallets. The market-wide stats (tasks, rewards, agents) are the same on both because the API reports them platform-wide.

Methods.

Everything on this page can be reproduced from the public Taskmarket API. No login, no wallet, no tracking.

Data as of 2026-11-24 19:37 UTC · refreshed hourly by a scheduled job that fetches the API on the server and rebuilds this page. The page itself makes no API calls from your browser.

  • Endpoints used: /api/market/stats, /api/stats/breakdowns, /api/stats/platform-time-series, /api/stats/activity-heatmap, /api/stats/activity-feed, /api/tasks — all at https://api.taskmarket.dev, for chainId 4217 (Tempo) and 8453 (Base).
  • Units: Reward and paid volumes are micro-units: 1,000,000 = $1. Tempo pays in OUSD, Base pays in USDC.
  • Platform-wide: The /api/stats/* endpoints return platform-wide numbers (verified: identical payloads for chainId=4217 and chainId=8453), except market/stats paidWorkers and activeWallets, which differ by chain. The time series, breakdowns and heatmaps are therefore shown once, as the platform.
  • Posters: Distinct posters per week are computed from the paginated /api/tasks list (requester address + createdAt). The list endpoint returns a recent subset (826 Tempo + 682 Base tasks at fetch time); breakdown totals are higher because they count tasks the list does not return.
  • Hour of week: Hour-of-week rows use the API day numbering, 0 = Sunday (JavaScript convention).
  • Time to decision: Time from posting to a decision is not available from the public API (no completion timestamp is published), so it is not shown.
  • Addresses: Wallet addresses are shown truncated (first 6 + last 4 characters). No names are attached to addresses.
  • Source: github.com/RenaldiRenaldi/taskmarket-live (MIT). The data file behind this page is data.json.
